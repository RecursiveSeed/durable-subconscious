## GitHub Discussions

**Title:** Durable Subconscious v0.3.0 public beta: persistent architectural memory for coding agents

Durable Subconscious is a local, file-backed knowledge and impact-analysis layer
for AI coding agents. It preserves evidence-backed project architecture,
ownership, dependency, lifecycle, risk, and test context across fresh sessions.

Install it in a project with:

```sh
npm install --save-dev github:RecursiveSeed/durable-subconscious
```

The v0.3.0 Codex integration has been independently exercised end to end. Adapters
for Claude Code, Cursor, GitHub Copilot, Gemini CLI, and OpenCode are available and
adapter-tested, but still need independent agent-session validation. If you use
one of those tools, the repository includes one shared acceptance protocol and a
structured report form. Results and failures are equally useful.

The core has no runtime dependencies or required cloud service and is
AGPL-3.0-only. Feedback, focused pull requests, and sanitized test reports are
welcome.
